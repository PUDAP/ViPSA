# Sequential recipe screening with incomplete reads

In a multi-device materials campaign, compare bounded settings on the same device with matched read bias, settling, delay and replicate count. Interleave anchor repeats, then validate the strongest setting on untouched devices in a different order. An isolated high apparent ratio is not an optimum if the immediate and delayed reads disagree or exact-condition repeats fail.

A user no-skip instruction can make weak-contact quality gates record-only for conservative exploratory sweeps; it does not override instrument, routing, read-compliance, energy or travel safety stops. Label weak/offset-dominated, wrong-direction and volatile read pairs unqualified rather than ranking them.

For interrupted acquisition, reconcile the live process and hardware state against raw branch CSV/JSON and the partial summary. A saved complete RESET sweep with no fixed-timing post-RESET read is a censored pair, not a verified switching cycle or device failure. A later low-bias diagnostic may characterize the current state but must not be substituted for the missing timed read. Verify output off, matrix open/nil, and safe retract before another device. For DC-IV visualization, plot measured points only on a semilog current axis, preserve timestamps, and offer editable SVG plus PNG.
