# Gated campaign review and DC-IV plot handoff

A substrate-level staged DOE can produce many clean forming events but almost no qualifying characterization. Review counts at **assignment → forming → conditioning → characterized → valid multi-cycle → endurance** with distinct denominators. A recipe withheld by an upstream gate is not a failed pulse/DC-IV recipe. A completed run with directionally inverted pulse reads is not successful switching. If the proposed Pareto-confirmation slots follow a DOE without replicated valid characterization, defer the confirmation label and use a predeclared activation/conditioning diagnostic instead.

For a request to plot the best DC-IV cycles, first inspect the saved raw CSV and summary. Extract only characterized sweep rows, group by `(cycle, phase, branch)`, assert the expected per-branch counts and cycle count, and preserve acquisition order. Plot all PF/PB/NF/NB branches on one semilog `|I|` versus **commanded voltage** axis. Color by cycle consistently across branches; distinguish branch direction with line styles. Add independent same-bias read-after-SET and read-after-RESET currents plus ON/OFF ratios, labeling only cycles that clear the gate. Use connected lines for sweeps, scatter for state reads. Never rerun hardware to regenerate a plot.

Example: Substrate 10 Device 13/DCIV-04 had five characterized cycles and 1,110 sweep rows (per cycle PF 71, PB 70, NF 41, NB 40). Independent `+0.05 V` ratios were 2.59, 2.37, 1.45, 1.57, 1.72: the first two were the strongest but did not establish sustained cycling. The saved figure was generated from raw rows rather than a forming/conditioning summary plot. Before any subsequent Zaber lateral move on a rig with a known under-platen collision risk, independently validate installed-system clearance and travel envelope; stage-Z readback and electrical cleanup alone are insufficient.
